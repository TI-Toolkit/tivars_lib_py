# Contribution Guidelines

Issues with code or docs and PRs fixing them are always welcome. Please ensure you are on the latest main branch commit *or* release version from GitHub or PyPI before opening. There's no set style or formatting guidelines; just ensure your code is clean, readable, and documented, with appropriate tests added to the suite if applicable.

To the end of maintaining code that is vetted by and useful for humans, **absolutely no PRs that were predominantly written by an LLM will be accepted**, nor any whose contents have been otherwise clearly not reviewed by a human. Bugs identified using coding agents are bugs all the same, so do open an issue if you've stumbled across one, but automated reports and PRs to address them which indicate no investment from you, the human, in assuring accuracy and code quality will be summarily rejected.
